# Community Call Archive

This is the searchable, chronological archive for Soroban Cookbook community
calls. Each call has one Markdown record named `YYYY-MM-notes.md`; the record
contains its notes, topics, decisions, action items, and links to its media.

plain-text topic names in both the table and the record so GitHub repository
search can find calls by date, topic, presenter, or action item. For example,
search this repository for `path:GOVERNANCE/notes Soroban` or a distinctive
topic phrase.

## Publishing a Call

1. Copy [the call notes template](./TEMPLATE.md) to
   `YYYY-MM-notes.md` and fill it in within 24 hours of the call.
2. Within 48 hours, upload the recording to the project's approved media host
   and add the stable video URL to the record and the table above. Store the
   video on the media host rather than committing video files to this
   repository.
3. Publish the transcript or timestamped outline and closed-caption link with
   the record. Review captions for accuracy and make sure the recording is
   accessible using its published link.
4. Link the notes and media from the call's GitHub Discussions follow-up, and
   link that follow-up from the record.
5. Check all links and update this index. Keep media URLs stable; if a video
   moves, update the record and index together.

Do not create an archive entry for an unpublished or unverified recording.
Leave unavailable media fields marked `Pending` in the notes until the owner
can provide a working link.

## Finding Calls

The index provides a quick date and topic overview. For detailed full-text
search, use GitHub's repository search with a date, topic, presenter, or phrase;
all call records remain Markdown files in this directory.
