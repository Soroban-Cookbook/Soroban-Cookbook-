This directory contains the canonical templates and guides for running Soroban Cookbook monthly community calls.

## Purpose

These documents ensure every community call is consistent, accessible, and productive. They are maintained by the core maintainer team and updated as the project evolves.

## Usage

1. Review the [Infrastructure Setup](./infrastructure-setup.md) for platform, calendar, registration, and recording configuration.
2. Open the [Agenda Template](./monthly-call-agenda-template.md) at least 5 days before the call.
3. Follow the [Format Guidelines](./monthly-call-format-guidelines.md) when configuring the call platform and promotion.
4. Review the [Moderation Guide](./monthly-call-moderation-guide.md) before each session to set expectations.
5. Use the [Q&A Process](./monthly-call-qa-process.md) to manage live questions.
6. Execute the [Follow-up Process](./monthly-call-followup-process.md) within 48 hours of the call ending.
7. Follow the [Recording Workflow](./recording/README.md) to upload, caption, and archive the recording.
