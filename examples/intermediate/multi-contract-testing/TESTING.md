# Testing Instructions

This document provides instructions for building and testing the multi-contract-testing example.

## Prerequisites

- Rust toolchain (1.96 or later)
- Soroban SDK 28.0.0-rc.1 or later
- `wasm32-unknown-unknown` target installed

```bash
rustup target add wasm32-unknown-unknown
```

## Running Tests

### From the Example Directory

```bash
cd examples/intermediate/multi-contract-testing
cargo test
```

### From the Workspace Root

```bash
cargo test -p multi-contract-testing
```

### Run Specific Test

```bash
cargo test test_cross_contract_call_with_state_verification
```

### Run with Output

```bash
cargo test -- --nocapture
```

```bash
cargo build --target wasm32-unknown-unknown --release
```

## Common Issues

### "cannot find type `TreasuryClient` in this scope"

**Cause**: The Soroban SDK automatically generates client types when contracts are built for testing.

**Solution**: This is expected and only works in test mode. The clients are generated by the SDK's testutils feature.

### "overflow-checks" or arithmetic errors

**Cause**: The workspace profile has overflow checks enabled.

**Solution**: This is intentional for safety. Ensure your arithmetic operations don't overflow.

### Tests hang or timeout

**Cause**: May indicate an infinite loop or deadlock in contract logic.

**Solution**: Review cross-contract call chains and ensure no circular dependencies.

## Manual Verification

If you cannot run cargo tests, you can manually verify:

1. **Code Structure**: Ensure all files are present (lib.rs, treasury.rs, governance.rs, test.rs)
2. **Imports**: Check that all imports are correct and types are defined
3. **Contract Traits**: Verify #[contract] and #[contractimpl] annotations are present
4. **Test Structure**: Confirm test module has #[cfg(test)] and tests have #[test]
5. **Client Generation**: SDK will generate TreasuryClient and GovernanceClient in tests
