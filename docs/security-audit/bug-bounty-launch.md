# Bug Bounty Program Launch Kit

The program policy is published in [`bug-bounty.md`](./bug-bounty.md), which
states that reports are accepted on a rolling basis. This launch kit prepares
announcement and outreach materials. Publication and participant activity
must be recorded only after maintainers verify them.

## Announcement Draft

**Title:** The Soroban Cookbook Bug Bounty Program Is Open

The Soroban Cookbook Bug Bounty Program invites security researchers to review
our educational Soroban contract examples, shared utilities, tests, and security
guidance. Eligible findings may receive rewards from **$10 to $1,000**, subject
to severity, validity, and the program's **$5,000 annual budget**.

Please review the [program scope and rules](./bug-bounty.md) before testing.
Submit findings privately through a
[GitHub Security Advisory](https://github.com/Soroban-Cookbook/Soroban-Cookbook-/security/advisories/new).
Do not post vulnerabilities in public issues or discussions. The program page
describes safe-testing requirements, report details, response targets, and
reward eligibility.

We welcome responsible reports that help make these examples safer to learn
from and build upon.

## Outreach Plan

1. Publish the announcement in
   [GitHub Discussions](https://github.com/Soroban-Cookbook/Soroban-Cookbook-/discussions)
   (Announcement category, if available), linking to the
   [program policy](./bug-bounty.md) and private reporting channel.
2. Cross-post the announcement to the `#soroban` channel in the
   [Stellar Developer Discord](https://discord.gg/stellardev), linking back to
   the Discussion for the canonical details.
3. Share a short reminder one week later through the same channels, then include
   a program reminder in the next community update.
4. Use project-owned social accounts only after maintainers confirm the account
   and approve the copy; do not create or imply an unofficial account.
