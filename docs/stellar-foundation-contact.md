# Stellar Foundation Contact

This document records the Soroban Cookbook project's outreach to and relationship with the Stellar Development Foundation (SDF).

---

## Purpose

The Soroban Cookbook is an independent, community-driven resource for building smart contracts on the Stellar network with Soroban. Establishing a formal relationship with the Stellar Development Foundation serves several goals:

- Ensure the cookbook stays aligned with the official Soroban SDK roadmap
- Coordinate on documentation gaps that the SDF team has identified
- Explore grant or sponsorship opportunities for sustained maintenance
- Identify potential co-promotion via official Stellar developer channels
- Get early notice of protocol changes that affect cookbook examples

## Project Summary

The following summary was sent to SDF as part of the initial outreach:

> **Soroban Cookbook** is an open-source, community-maintained collection of smart-contract recipes, guides, and best practices for the Soroban platform. The cookbook currently contains:
>
> - 50+ smart-contract examples across DeFi, NFT, governance, and token categories
> - Comprehensive testing, security, and performance documentation
> - Production-grade project templates (fungible tokens, NFT marketplace, DAO governance)
> - An active contributor community with monthly calls
>
> We are reaching out to discuss alignment with the official Soroban developer documentation, potential grant opportunities, and how the cookbook can best serve the Stellar developer community.

## Partnership Discussion Topics

When a meeting is scheduled, the following topics are on the agenda:

1. **Documentation alignment** — which topics in the official docs have gaps the cookbook can fill, and vice versa
2. **SDK compatibility commitment** — how quickly should the cookbook track new SDK releases; can SDF provide advance notice of breaking changes?
3. **Grant or sponsorship** — does the cookbook qualify for SDF developer grants? What is the application process?
4. **Co-promotion** — can SDF link to the cookbook from the official Soroban documentation or developer portal?
5. **Early access** — can cookbook maintainers join the SDF developer preview program for new protocol features?
6. **Community events** — joint presence at Meridian, Stellar developer workshops, or hackathons
