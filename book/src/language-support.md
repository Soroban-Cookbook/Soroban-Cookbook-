# Language Support

The Soroban Cookbook is currently maintained in English. Use the language menu
in the documentation toolbar to select a language preference and see its
translation status. Until a translation is published, selecting that language
continues to show the English content.

## Translation Status

| Language | Status |
| --- | --- |
| English | Available |
| Spanish | English fallback |
| French | English fallback |

English is the fallback language. Your language preference is saved in this
browser and remains in effect as you navigate the documentation. If the saved
preference is unknown or invalid, the site resets it to English.

Translations can be contributed through the usual documentation pull request
process. A language should be enabled in the selector once its translated pages
are published.
