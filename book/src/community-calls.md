# Community Calls

The Soroban Cookbook hosts monthly community calls for project updates, demos,
and questions. Find published call notes, recordings, transcripts, captions,
and follow-up actions in the
[Community Call Archive](https://github.com/Soroban-Cookbook/Soroban-Cookbook-/tree/main/GOVERNANCE/notes).

The repository's [archive index](https://github.com/Soroban-Cookbook/Soroban-Cookbook-/blob/main/GOVERNANCE/notes/README.md)
lists calls by date and topic. Its Markdown records are searchable by topic,
presenter, and action item using GitHub repository search.

For the schedule and participation details, see
[Monthly Community Call Governance](https://github.com/Soroban-Cookbook/Soroban-Cookbook-/blob/main/GOVERNANCE/README.md).
The [follow-up process](https://github.com/Soroban-Cookbook/Soroban-Cookbook-/blob/main/GOVERNANCE/monthly-call-followup-process.md)
explains how recordings and notes are published after each call.
