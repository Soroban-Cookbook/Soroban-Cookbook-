# Guides

The guides in this section take you from "install the toolchain" to
"deploy a contract to testnet".  Each guide points at runnable examples, and
every snippet is covered by the repository test-suites.

| Guide | What you will do |
|-------|------------------|
| [Getting Started](./getting-started.md) | Install Rust, the Stellar CLI and the Wasm target |
| [macOS Setup Guide](./macos-setup.md) | Get the toolchain working on macOS |
| [Contract Development](./contract-development.md) | Write, test and ship your first contract |
| [Testing Guide](./testing.md) | Mock auth, travel through time, assert on events |
| [Mobile Testing Guide](./mobile-testing.md) | Test your contract from a mobile wallet |
| [Local Simulation](./local-simulation.md) | Run a local Stellar node |
| [Deployment Guide](./deployment.md) | Deploy to testnet and mainnet |
| [Ethereum to Soroban](./ethereum-to-soroban.md) | Translate Solidity habits to Soroban |
| [Project Templates](./docs/project-templates.md) | Start from a template project |
| [Security Checklist](./security-checklist.md) | Review a contract before shipping |
| [Video Creation Tools](./video-creation.md) | Record the walkthrough videos |
